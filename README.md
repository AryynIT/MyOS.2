# ⚡ MiniOS

Desktop Environment berbasis Python + Tkinter yang jalan di terminal Linux (tested: Kali Linux).

## Fitur
- 🪟 Window Manager (drag, minimize, maximize, close)
- 🖥️ Fullscreen Mode (F11)
- 💻 Terminal emulator dengan command execution
- 📝 Notepad dengan save/open file
- 📁 File Manager
- ⚙️ Settings panel
- 🎨 Taskbar + Start Menu

## Instalasi

```bash
git clone https://github.com/USERNAME/minios.git
cd minios
chmod +x install.sh
./install.sh
```

## Cara Pakai

```bash
minios
```

Atau langsung:
```bash
python3 main.py
```

## Hotkeys
| Key | Fungsi |
|-----|--------|
| F11 | Toggle Fullscreen |
| Esc | Keluar dari fullscreen |

## Requirements
- Python 3.8+
- python3-tk (`sudo apt install python3-tk`)
